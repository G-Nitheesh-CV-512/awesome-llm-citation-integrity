# Tutorials and Learning Resources

This section contains authoritative documentation, tutorials, and learning resources for understanding scholarly metadata, citation verification, reference extraction, retrieval systems, and hallucination evaluation.

## 1. Crossref REST API Documentation

- **Organization:** Crossref
- **Type:** Scholarly metadata documentation
- **Resource:** https://www.crossref.org/documentation/retrieve-metadata/rest-api/
- **Purpose:** Provides documentation for searching and retrieving scholarly metadata through the Crossref REST API.
- **What it teaches:** DOI lookup, bibliographic metadata retrieval, work searches, filtering, and structured metadata queries.
- **Why it is relevant:** Crossref can be used to verify whether an LLM-generated DOI and bibliographic record correspond to a real scholarly publication.

## 2. OpenAlex API Quickstart

- **Organization:** OpenAlex
- **Type:** Scholarly literature API tutorial
- **Resource:** https://developers.openalex.org/quickstart
- **Purpose:** Introduces the OpenAlex scholarly knowledge graph and demonstrates how to search and retrieve scholarly works and related entities.
- **What it teaches:** Searching institutions, works, authors, sources, and other scholarly entities through the OpenAlex API.
- **Why it is relevant:** OpenAlex provides an independent source for cross-checking papers, authors, venues, and scholarly metadata generated by language models.

## 3. Semantic Scholar Academic Graph API Tutorial

- **Organization:** Semantic Scholar / Ai2
- **Type:** Scholarly literature API tutorial
- **Resource:** https://webflow.semanticscholar.org/product/api/tutorial
- **Purpose:** Provides a practical introduction to using the Semantic Scholar APIs for scholarly literature retrieval.
- **What it teaches:** Searching for papers and authors, retrieving paper details, finding recommendations, and working with scholarly datasets.
- **Why it is relevant:** Semantic Scholar can be used as an independent verification source for papers, authors, citations, references, and related research.

## 4. GROBID Quickstart Documentation

- **Organization:** GROBID
- **Type:** Scholarly PDF and bibliography processing tutorial
- **Resource:** https://grobid.readthedocs.io/en/latest/getting_started/
- **Purpose:** Provides instructions for installing and running GROBID for extracting structured information from scholarly documents.
- **What it teaches:** Running GROBID, processing scholarly PDFs, extracting bibliographic information, and using the service for reference processing.
- **Why it is relevant:** Citation-integrity auditing requires extracting references from papers so that bibliographic records can be checked systematically.

## 5. Hallucination in Large Language Models — ACL Tutorial

- **Authors:** Vipula Rawte, Aman Chadha, Amit Sheth, Amitava Das
- **Year:** 2024
- **Venue:** LREC-COLING 2024 Tutorial Summaries
- **Resource:** https://aclanthology.org/2024.lrec-tutorials.11/
- **Type:** Academic tutorial
- **Purpose:** Introduces hallucination in large language models and discusses benchmarking, detection, mitigation, and limitations of existing approaches.
- **What it teaches:** Core concepts and research approaches for understanding and evaluating LLM hallucinations.
- **Why it is relevant:** Citation fabrication is closely related to hallucination, making this tutorial useful for understanding the broader reliability problem studied in this repository.

## Suggested Learning Path

The resources can be used in the following order:

1. **Crossref REST API** — learn how scholarly metadata and DOI records can be verified.
2. **OpenAlex Quickstart** — learn independent scholarly literature retrieval.
3. **Semantic Scholar API Tutorial** — learn paper, author, citation, and reference lookup.
4. **GROBID Quickstart** — learn how references can be extracted from scholarly PDFs.
5. **ACL Hallucination Tutorial** — understand hallucination evaluation and its relationship to citation reliability.

Together, these resources provide a practical foundation for building and evaluating citation-verification workflows for large language models and search-augmented systems.

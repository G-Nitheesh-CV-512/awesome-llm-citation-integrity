# GitHub Implementations

This section contains open-source implementations and research repositories relevant to citation evaluation, hallucination detection, factuality assessment, retrieval-augmented generation, and scholarly reference processing.

## 1. ALCE — Enabling Large Language Models to Generate Text with Citations

- **Repository:** https://github.com/princeton-nlp/ALCE
- **Organization:** Princeton NLP
- **Purpose:** Official code and data for the ALCE benchmark, which evaluates LLM-generated text with citations.
- **Key capabilities:** Citation-quality evaluation, retrieval, baseline generation, post-hoc citation generation, and automatic evaluation.
- **Why it is relevant:** This is one of the most directly relevant implementations for the project because it provides an established framework for evaluating citations generated by language models.

## 2. RAGTruth — A Hallucination Corpus for Retrieval-Augmented Language Models

- **Repository:** https://github.com/ParticleMedia/RAGTruth
- **Organization:** ParticleMedia
- **Purpose:** Dataset, baseline models, and evaluation resources for studying hallucinations in retrieval-augmented generation.
- **Key capabilities:** Word-level hallucination annotations, RAG response analysis, training/evaluation resources, and baseline implementations.
- **Why it is relevant:** It can support experiments on whether retrieved evidence actually grounds generated claims in search- or retrieval-based systems.

## 3. HaluEval — A Hallucination Evaluation Benchmark for LLMs

- **Repository:** https://github.com/RUCAIBox/HaluEval
- **Organization:** RUCAIBox
- **Purpose:** Official repository for the HaluEval hallucination benchmark.
- **Key capabilities:** 35K hallucination samples, data generation, model evaluation, and analysis across question answering, dialogue, and summarization.
- **Why it is relevant:** It provides a broad hallucination benchmark that can be used to study the relationship between general LLM hallucination and citation fabrication.

## 4. FActScore — Fine-grained Atomic Evaluation of Factual Precision

- **Repository:** https://github.com/shmsw25/factscore
- **Organization:** Official FActScore implementation
- **Purpose:** Evaluates factual precision in long-form language-model generation at the level of atomic facts.
- **Key capabilities:** Fact decomposition, evidence retrieval, factuality scoring, released human annotations, and evaluation of language-model outputs.
- **Why it is relevant:** Citation fabrication can occur when a generated statement is not supported by evidence. FActScore provides a useful complementary framework for measuring factual support.

## 5. GROBID — GeneRation Of BIbliographic Data

- **Repository:** https://github.com/kermitt2/grobid
- **Organization:** GROBID open-source project
- **Purpose:** Extracts structured scholarly information from PDF documents.
- **Key capabilities:** Metadata extraction, full-text extraction, citation and bibliography parsing, reference extraction, and structured TEI/XML output.
- **Why it is relevant:** A citation-fabrication audit needs to inspect and compare bibliographic references. GROBID can help automatically extract reference lists and citation metadata from scholarly PDFs.

## How These Implementations Support the Project

The repositories cover complementary parts of a citation-integrity workflow:

| Repository | Main role |
|---|---|
| **ALCE** | Citation generation and citation-quality evaluation |
| **RAGTruth** | RAG hallucination analysis |
| **HaluEval** | General LLM hallucination evaluation |
| **FActScore** | Fine-grained factual-support evaluation |
| **GROBID** | Scholarly reference and citation extraction |

Together, these implementations provide reusable resources for evaluating generated claims, checking evidence support, analyzing hallucinations, and processing bibliographic references.
